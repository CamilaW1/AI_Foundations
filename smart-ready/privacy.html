Privacy & Data Use

Local first, minimum necessary data

Smart Ready is a learning prototype. Most AI processing is designed to happen in the browser, and the app avoids asking for data it does not need.

No paid cloud LLM No app account required No first-party ads/analytics
Quick summary

What happens to your data?

📷 Camera

Processed in your browser for Build 1.

🧠 Local LLM

Prompts and answers run on-device through WebLLM.

📅 Calendar files

Imported .ics files are parsed locally.

📄 Documents

TXT, MD and supported PDF files are processed locally for retrieval.

🌦 Weather

Typed city + forecast request go to Open-Meteo.

💾 Progress

Learning progress, memory and small model/checklist data can be stored in browser storage.

What stays on your device

Build 1 photos: captured training images are used in the browser. The current prototype does not intentionally upload them to an AI server.

Saved vision model: compact classifier data and class names can be stored in localStorage so later builds can reuse the detector.

Builds 2–5 local LLM: the current SmolLM2 model runs through WebLLM in the browser. Prompts are not sent to OpenAI or another paid cloud LLM API by this code.

Calendar: imported .ics text is parsed locally. Only selected event fields are used as AI context.

Memory: preferences selected in Build 5 are stored locally on that device.

Documents: TXT/MD and supported PDF documents are read locally. Retrieval chunks are generated in the browser.

What goes to external services

Open-Meteo: Build 3 sends the city search and latitude/longitude weather request needed for forecast data. Precise browser GPS is not requested.

Libraries and model files: JavaScript libraries, WebLLM/model files, TensorFlow.js assets and PDF.js can be downloaded from their hosting/CDN providers. Those providers may receive normal technical request data such as IP address, browser details and request time.

Hosting: the current site is served by GitHub Pages, which may process standard request/security logs under GitHub's own policies.

Permissions

Camera: requested only when you start a camera feature. You can deny or revoke it in browser settings.

Calendar: the current build does not request your Google/Microsoft calendar password or automatic account access.

Location: weather currently uses a city typed by the user, not precise browser geolocation.

AI agents, memory and documents

Build 4 exposes only the tools defined by the learning app. The agent cannot automatically access arbitrary apps, accounts or device data.

Build 5 distinguishes saved preferences from document facts and demonstrates retrieval before generation. AI answers can still be incomplete or wrong.

Do not enter passwords, financial details, medical records or other highly sensitive information into this learning prototype.

Storage and deletion

Some temporary data disappears on refresh. Learning progress, local memory, checklist data and compact model data may remain in localStorage until site data is cleared.

To remove it, open the browser's site settings for this website and clear site data/storage. Camera permission can also be revoked there.

AI safety

Suggestions are not guarantees

Smart Ready deliberately teaches uncertainty, human review, tool limits, grounded sources and evals. Do not rely on this prototype for medical, legal, emergency or other safety-critical decisions.
