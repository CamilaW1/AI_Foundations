Privacy & Data Use

What stays on your device — and what leaves it

This page describes the current Smart Ready learning prototype. It is written in plain language so users can understand how camera, calendar, weather and local AI features use data.

No paid AI API No account required by the app Local AI processing
📱

Stays on your device

The app is designed so the most personal learning data stays in the browser whenever possible.

Camera photos

Project 1 processes captured training photos in the browser for the image classifier. This prototype does not intentionally upload those photos to an AI server.

Local LLM prompts and answers

Projects 2 and 3 use a browser-based local LLM through WebLLM. The app does not send those prompts to OpenAI or another paid cloud LLM API.

Imported calendar files

Project 3 reads imported .ics calendar files in the browser. The original calendar file is not intentionally uploaded by this app.

Saved checklist data

Some confirmed checklist/context data may be stored in your browser's localStorage on that device so the prototype can remember it locally.

🌐

Data sent to external services

Some features need files or data from third-party services. The app tries to send only what is needed.

Weather

In Project 3, the city name you type is sent to Open-Meteo's geocoding service. The resulting coordinates are then used to request current weather. The app does not request your browser's precise GPS location for this feature.

Libraries and model files

The browser downloads JavaScript libraries and local-model files from third-party hosting/CDN services. Like normal web requests, those providers may receive technical request information such as IP address, browser/device details and request time.

Website hosting

The site is currently served through GitHub Pages. GitHub may process standard web request information as part of hosting and security operations.

Permissions

You choose when sensitive features start

📷
Camera

The browser asks for camera permission when you choose to start the camera. You can deny or revoke permission in browser settings.

📅
Calendar

The current Project 3 prototype does not ask for your Google/Microsoft calendar password or automatic account access. You choose an .ics file yourself or add events manually.

📍
Location

The current weather flow asks you to type a city. It does not request precise browser geolocation.

Storage & deletion

How to clear local data

Refreshing the page can clear temporary in-memory data such as the current camera classifier. Data saved in localStorage may remain until the site's browser storage is cleared.

To remove locally saved prototype data:

Open your browser's site settings for this website and clear site data/storage. You can also remove camera permission there.

AI safety

AI suggestions can be wrong

Generated checklists are suggestions, not guarantees. The product intentionally includes a review step before a checklist is treated as final. Do not rely on this prototype for safety-critical, medical, legal or emergency decisions.

Children & sensitive information

Keep the prototype low-data

The app does not need names, birthdays, passwords, medical information, financial information or other sensitive personal details to demonstrate these projects. Avoid entering sensitive information into plans, event titles or checklists.

Tracking & advertising

Current prototype

The Smart Ready project currently does not intentionally include advertising, an advertising SDK, or first-party analytics/tracking code. Hosting providers and external resource providers may still process standard technical request information when your browser connects to them.

Cost rule

No paid AI service is enabled

The current projects do not use a paid OpenAI API or another paid cloud LLM API. Any future feature that can create token, API, credit or usage-based charges must be reviewed and explicitly approved before it is connected.
